## ✨ Características Principales

- **Todo en Uno:** El archivo ejecutable (`.exe`) incluye el juego y el motor de ejecución integrados.
- **Guardado Persistente en `save data`:** Tus partidas (`.sav`) y estados rápidos (`.ss1`, `.ss2`, etc.) se guardan automáticamente y de forma limpia en la carpeta `save data`.
- **100% Portable:** Puedes llevar el ejecutable y tu carpeta `save data` en un pendrive o USB sin perder progresos.
- **Rendimiento Fluido:** Optimizado para PC con una tasa de cuadros estable y sin lag.

---

## 🚀 Cómo Jugar

Es muy sencillo:

1. Ejecuta **`lanzador.exe`**.
2. Al iniciar, el juego creará la carpeta **`save data`** a su lado para gestionar tus avances.
3. ¡Disfruta del juego!

## 🎮 Controles por Defecto (Teclado)

- **Salto:** `Tecla X`
- **Correr / Lanzar Fuego:** `Tecla Z`
- **Moverse / Agacharse:** `Flechas Direccionales`
- **Pausar (Start):** `Tecla Enter`
- **Guardar Estado Rápido:** `Shift + F10`
- **Cargar Estado Rápido:** `F10`
